# Home Automation Simulator

A Python-based home automation simulation developed for my A-Level Computer Science NEA. The application allows users to explore how household appliances affect energy consumption and electricity costs, helping them understand how smarter device management can improve energy efficiency.

## Features

- **User authentication:** Registration and login functionality using an SQLite database.
- **Interactive graphical interface:** Built with Pygame, featuring menus, settings and room maps.
- **Customisable home simulation:** Choose between three house layouts and explore different rooms.
- **Appliance management:** Browse appliance categories, place items into compatible room slots, switch devices on or off, and replace or remove items.
- **Energy and cost calculations:** Track simulated electricity consumption and costs as devices operate.
- **Daily and weekly reports:** Review energy usage and costs, examine appliance-level consumption, and receive suggestions for improving energy efficiency.
- **User settings:** Toggle fullscreen mode and display the FPS counter.

## Technologies Used

- **Python** — application logic, simulation and algorithms.
- **Pygame** — graphical user interface and interactive elements.
- **SQLite** — relational database storage and user account management.
- **SQL** — querying and managing stored data.
- **Object-oriented programming (OOP)** — reusable classes and separation of application components.

## How It Works

The user registers or logs in to proceed with the menu selection. The user has the option to choose among any three house plans that will be explored. Rooms can be configured, and a compatible appliance can be placed in any slot.

During the simulation, active appliances are included in the overall energy consumption and cost of electricity. At the end of each simulated day, a summary report is provided together with recommendations on how to improve energy efficiency.
